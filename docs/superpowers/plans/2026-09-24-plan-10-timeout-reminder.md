# PLAN-10 超时、提醒与定时任务实施计划

## 目标

围绕接单截止时间和维修截止时间建立可重复执行的提醒与超时任务；接单超时复用统一派单，维修超时不改变工单状态。

## 任务

1. 以失败测试定义提醒枚举、时间窗口、接收人与唯一键防重行为。
2. 扩展工单和提醒 Mapper，实现每批有限数量的索引扫描与原子插入。
3. 实现接单提醒、接单超时、完成提醒、完成超时服务，逐单隔离异常。
4. 增加职责分离的 Spring Scheduling 任务和统一配置。
5. 用真实 MySQL 构造截止时间数据，验证防重、改派、状态不变和 EXPLAIN 索引。
6. 更新接口说明和 `doc/verify/PLAN-10验收记录.md`，只记录专项测试，不生成截图。

## 已确认边界

- 不使用 Redis 超时锁；依靠状态、截止时间、派单 CAS 与提醒唯一键。
- 完成超时状态范围为维修中、返工中、已中断。
- `receiver_id` 保存 `sys_user.id`，不是 `repair_worker.id`。
- PLAN-9 请假 Service/任务由独立阶段实现；本阶段不改变其调度配置，只实现工单提醒与超时处理。
- 不运行无关全量测试，不生成测试截图。
