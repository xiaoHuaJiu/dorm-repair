# 专项规则

本目录用于保存特定数据库、中间件或工具的附加开发规则。

## 使用方式

- 仅在项目实际采用某项技术且通用规则不足时新增对应文档。
- 文件名使用技术名称的小写形式，例如 `mysql.md`、`redis.md`、`minio.md`。
- 专项规则不得与 `doc/rules/project.md` 冲突；如需例外，应写明原因和适用范围。
- 引入或移除专项规则时，应同步检查架构、数据库和安全文档。

## 专项规则建议包含

- 适用范围和版本。
- 命名、连接与配置约束。
- 数据结构或对象结构约束。
- 性能、并发和容量注意事项。
- 安全、备份、恢复和故障处理要求。
- 本地开发、测试与生产环境的差异。
