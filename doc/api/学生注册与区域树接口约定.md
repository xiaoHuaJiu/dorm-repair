# 学生注册与区域树接口约定

## 学生注册

请求字段：

- `username`
- `password`
- `confirmPassword`
- `realName`
- `phone`

服务端必须忽略客户端传入的角色字段，并固定创建 `role_type = STUDENT` 的账号。注册成功仅返回成功结果，不签发登录会话或令牌。

## 区域架构树

区域树的目标契约为“单位/校区 → 区域 → 楼栋 → 房间”四级结构。每个节点至少包含节点标识、名称、类型和子节点数组，房间为末级节点。报修提交使用选中节点对应的校区、区域、楼栋和房间信息；服务端需要验证四级节点之间的父子关系，不能只依赖客户端联动限制。

当前 HTML 原型已经按四级结构演示。正式后端的 DDL、枚举、校验和接口实现仍需单独升级后才能满足该目标契约。

接口路径及权限见 [`基础配置接口.md`](基础配置接口.md)。
