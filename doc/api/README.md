# 接口文档

本目录用于维护前端与后端之间的接口契约。

总联调文档为 [`前端联调接口说明.md`](前端联调接口说明.md)。每新增或变更接口时必须同步维护。

页面级接口覆盖情况和后端并行开发阻塞项见 [`前端页面接口依赖矩阵.md`](前端页面接口依赖矩阵.md)。

## 单个接口应包含

- 接口名称和用途。
- 请求方法与路径。
- 所需身份、角色和权限。
- 路径参数、查询参数、请求头和请求体。
- 参数类型、是否必填、校验规则和示例。
- 成功响应结构和示例。
- 业务错误码、含义及客户端处理建议。
- 幂等性、并发行为和限流要求。
- 涉及文件上传时的类型、大小和数量限制。

## 编写约束

- 字段名称、类型、可空性和枚举值必须与实现保持一致。
- 时间、金额、分页和状态字段应采用项目统一格式。
- 不在文档示例中使用真实个人信息、生产数据、访问令牌或密钥。
- 接口发生不兼容变化时，应明确影响范围和迁移方式。
