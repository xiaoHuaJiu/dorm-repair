# 学生确认、评价与返工接口

## 通用约定

- 基础路径 `/api/student/repair-orders`，仅学生角色可访问，身份取自 JWT。
- 成功响应：`{"code":0,"message":"success","data":null}`。
- 参数错误为 HTTP 400 / 10001；未登录 401 / 10002；越权 403 / 17002；不存在 404 / 17001；状态冲突 409 / 10005；重复评价 409 / 17005。
- 前端不得传学生或维修人员 ID。提交按钮在请求期间必须禁用并显示加载状态，响应后重新查询详情。
- 图片字段只传已上传对象引用；当前没有文件上传接口。

## 确认完成

`POST /api/student/repair-orders/{id}/confirm`，无请求体。仅本人且状态为 `3-待确认` 可操作，成功后状态为 `6-已完成`，`confirmTime` 与 `completeTime` 使用同一时间。

## 提交评价

`POST /api/student/repair-orders/{id}/evaluation`

```json
{"score":5,"content":"维修及时，问题已解决"}
```

仅本人已完成工单可评价一次；评分为 1 至 5，内容可选且最多 1000 字符。空白内容按 `null` 保存，无负责人时返回 409。

## 申请返工

`POST /api/student/repair-orders/{id}/rework`

```json
{"reason":"故障再次出现","imageUrls":["repair/2026/rework-1.jpg"]}
```

仅本人且状态为 `3-待确认` 可操作。原因必填且最多 1000 字符；图片最多 9 个，每项最长 500 字符。成功后进入 `4-返工中` 并保留负责人。第二次返工产生中等级告警，第三次及以后产生高等级告警并标记异常。
