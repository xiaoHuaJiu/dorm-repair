HTTP 测试覆盖：

- 成功响应解包。
- Bearer 令牌注入。
- 业务错误转为 `ApiError`。
- 401 触发登录状态清理。
- 403 保留权限错误且不触发未登录处理。
- 主动取消请求不显示网络错误。
- 相同防重键在首个请求结束前拒绝重复提交，结束后自动释放。
- 网络异常和非标准响应使用安全提示。

## 人工核对

- `@` 同时配置于 Vite 和 TypeScript。
- Element Plus 与 Vant 的主色均映射到同一红色主题令牌。
- 全局样式包含键盘焦点和减少动态效果支持。
- `src` 已具备 `api/assets/components/config/constants/layouts/router/stores/styles/types/utils/views` 分区，页面目录按角色拆分。
- API 类型不包含业务演示数据；分页集合字段按总联调文档暂定为 `records`。
