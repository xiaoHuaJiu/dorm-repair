# 区域配置四级原型验收记录

## 验收范围

- 管理员区域树采用“学校/单位 → 区域 → 楼栋 → 房间”四级结构。
- 编辑模式下，楼栋可以新增房间，房间为末级节点。
- 有下级节点的节点禁止删除，并提示“请先删除下级节点”。
- 学生提交报修时，校区、区域、楼栋、房间四级下拉框逐级联动。
- 任一上级选择变化后，后续下拉框清空并恢复禁用状态。

## 验收方式

- 运行 `node --test prototype/tests/state.test.js prototype/tests/pages.test.js prototype/tests/flows.test.js`。
- 对 `prototype/assets/*.js` 执行 `node --check`。
- 在浏览器中检查管理员四级区域树和学生报修弹窗的逐级联动。

## 边界说明

本记录只覆盖 HTML 原型。正式后端仍采用 PLAN-2 的三级位置 DDL，四级房间节点对应的数据库、枚举、接口与服务校验尚未实施。

## 验收结果

- JavaScript 语法检查：通过。
- 原型自动化测试：51 个通过，失败 0。
- 管理员端浏览器检查：可展开至房间层；楼栋编辑操作包含新增房间，房间只有删除入口。
- 学生端浏览器检查：选择校区、区域和楼栋后，房间下拉框成功加载对应房间。
