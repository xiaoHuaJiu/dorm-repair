# FRONTEND F3 验收记录(2026-09-24)

## 验收范围

- F3-01:三端页面布局——学生端/维修端移动布局(顶栏 + 页头 + 内容 + 底部导航),管理员端桌面布局(顶栏 + 分组侧栏 + 内容区)。
- F3-02:工单状态组件,八个状态统一文案、颜色。
- F3-03:移动端工单卡片与管理端工单表格行,整卡/整行可点击,操作按钮阻止冒泡,无多余“查看详情”按钮。
- F3-04:胶囊筛选组件(状态、区域、负责人筛选由页面层组合使用)。
- F3-05:生命周期轨迹组件,最新在前,覆盖操作类型、状态变化、原因与负责人变更。
- F3-06:通用反馈状态——骨架屏、空数据、错误与重试、提交中状态。
- F3-07:确认弹窗、表单弹窗、图片上传与预览。

## 人工验证路径

1. 启动后端与前端,登录学生账号进入 `/student/home`:
   - 核对顶栏(品牌、头像、姓名、退出)、页头与底部导航(仅“首页”可见,其余待路由接入)与原型一致。
   - 维修人员登录 `/worker/home`,核对三栏导航基线(仅“工作台”可见)。
   - 管理员登录 `/admin/dashboard`,核对侧栏“工作台”分组与原型侧栏样式,未注册分组整体隐藏。
2. 组件视觉可在后续 F5—F8 页面中按验收记录逐页核对;本阶段以单测断言 + 布局壳人工目检为验收口径。
3. 键盘验证:卡片/行可 Tab 聚焦,Enter/空格可触发;弹窗 Esc 关闭;提交中 Esc 不关闭。

## 后端阻塞项

- 图片上传接口缺失:`ImageUploader` 仅保留预览/选择/移除,页面层在接口就绪前禁用选择并提示,不生成假 URL。
- 流转记录 `flows` 无操作人与负责人姓名:组件以 `operatorNameOf`/`assigneeNameOf` 回调衔接,后端补充姓名字段后移除。
- 后续流转操作类型(转派、返工、确认、取消等)数值未定义,待后端扩展 `RepairOrderOperationTypeEnum` 后补充映射。
