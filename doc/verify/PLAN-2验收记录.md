# PLAN-2 验收记录

## 一、记录说明

- 对应需求：`doc/requirements/PLAN-2.md`
- 阶段名称：基础配置 CRUD、用户注册与凭证安全能力建设
- 记录性质：阶段完成后的回补验收
- 回补复验日期：2026-09-23
- 验收结论：后端范围通过；前端基础配置页面按已确认边界暂未实现

## 二、验收范围

本阶段验收以下后端能力：

1. 学生公开注册和密码安全；
2. 故障类型 CRUD、分页、条件查询和启停；
3. 位置三级树 CRUD、层级校验和公共级联查询；
4. 维修人员创建、账号绑定、修改、详情、分页和状态维护；
5. 维修人员技能与负责区域的批量配置；
6. 工作时间方案 CRUD、分页、启停和重叠校验；
7. 管理接口、公共选择接口的角色权限；
8. 真实 MySQL 下的完整配置链路和事务一致性。

## 三、验收结果

### 3.1 密码安全与学生注册

| 验收项 | 结果 | 验收依据 |
|---|---|---|
| 密码统一使用 BCrypt，不存明文 | 通过 | `UserRegistrationServiceTest`、`Plan2MySqlIntegrationTest` |
| 登录使用统一 `PasswordEncoder.matches` | 通过 | `AuthServiceTest` |
| 学生可公开注册并登录 | 通过 | 注册服务测试与真实 MySQL 集成链路 |
| 用户名唯一及并发唯一冲突转换 | 通过 | Service 校验、数据库唯一索引、冲突异常处理 |
| 密码确认校验 | 通过 | 注册服务测试 |
| 公开注册不能指定管理员或维修人员角色 | 通过 | 服务端固定学生角色，真实链路验证角色注入无效 |
| 密码和哈希不返回客户端、不写日志 | 通过 | 注册响应模型不含密码字段，日志未输出密码或完整哈希 |

### 3.2 故障类型

新增、修改、详情、分页、条件查询、排序、启停均已实现并通过测试；业务编码由数据库唯一索引兜底，不提供物理删除接口。公共接口只返回启用项。

### 3.3 位置树

三级位置树新增、修改、启停、树查询和子节点级联查询已实现并通过测试。实现遵循当前 DDL：

- `1`：校区或单位；
- `2`：区域；
- `3`：楼栋。

已验证父节点不存在或停用、非法跨级、同父同类型同名、停用祖先过滤等规则。当前 DDL 未定义房间节点，因此本阶段未虚构第四级房间类型。

### 3.4 维修人员

| 验收项 | 结果 |
|---|---|
| 创建新用户并绑定维修人员 | 通过 |
| 绑定已有维修人员角色用户 | 通过 |
| `user_id`、`worker_no` 唯一 | 通过 |
| 列表、条件查询和详情 | 通过 |
| 基础信息修改 | 通过 |
| 账号状态和维修业务状态独立维护 | 通过 |
| 创建失败时事务回滚、不留半成品 | 通过 |

### 3.5 技能与负责区域

技能和负责区域均采用事务化差集保存，支持重复提交幂等。技能关系使用 `UNIQUE(worker_id, fault_type_id)` 保留历史关系，通过启停实现取消和恢复。

负责区域支持校区、区域和楼栋三种粒度，已验证区域/楼栋归属、重复范围以及上级范围覆盖下级范围。停用维修人员禁止新增或修改配置，但管理员仍可查询其历史配置。

### 3.6 工作时间

新增、修改、详情、分页、按日期查询和启停均已实现。已验证日期倒置、上下班时间倒置、生效区间重叠、边界相接视为重叠、修改排除自身以及重新启用时复查冲突。

## 四、完整链路验收

`Plan2MySqlIntegrationTest` 在真实 MySQL 上完成以下链路：

```text
学生注册并验证角色不可注入
→ 管理员登录
→ 创建故障类型
→ 创建三级位置
→ 创建维修人员
→ 配置技能
→ 配置负责区域
→ 创建工作时间方案
→ 查询公共选择数据和维修人员组合详情
→ 验证跨角色 403
→ 验证事务回滚后无残留测试数据
```

结果：链路通过，数据库未残留该测试创建的业务数据。
