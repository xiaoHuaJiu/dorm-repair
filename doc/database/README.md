# 数据库文档

本目录用于维护 MySQL 8 的表结构、字段说明、索引、约束及数据迁移说明。

## 每张表应包含

- 表名、用途和所属业务模块。
- 主键策略及字段定义。
- 字段含义、类型、默认值、可空性和取值约束。
- 外键或业务关联关系。
- 唯一索引、普通索引及其对应的查询场景。
- 创建时间、更新时间等审计字段约定。
- 数据生命周期、归档或清理要求。
- 结构变更的迁移与回滚方案。

## 设计约束

- MySQL 是核心业务数据的最终事实来源。
- Redis 中的数据必须明确过期策略、失效处理和回源方式。
- MinIO 对象不直接写入数据库，数据库保存对象标识及必要元数据。
- 表、字段和索引不得仅凭推测创建，应能够追溯到已确认需求或查询场景。
- 涉及删除、覆盖或不可逆迁移时，执行前必须获得明确确认并准备备份或回滚措施。
