# 安全文档

本目录用于记录身份认证、权限控制、敏感数据处理及系统安全边界。

## 建议内容

- 学生、维修人员、管理人员等角色的权限矩阵。
- Spring Security 认证和授权流程。
- JWT 的签发、校验、刷新、失效和密钥轮换策略。
- 密码存储、登录失败处理及会话安全要求。
- 接口级、数据级和对象级权限控制。
- 参数校验、文件上传、跨域、重放、越权和注入风险防护。
- 日志脱敏、审计记录和异常信息暴露边界。
- MySQL、Redis、MinIO 及部署环境的访问控制。
- 密钥、密码和其他敏感配置的注入与管理方式。

## 基本原则

- 后端是权限判断的最终执行方。
- 默认拒绝未经明确授权的访问。
- 不在代码、测试、文档或日志中保存密钥、个人信息和真实生产数据。
- 安全规则应具备可验证的测试或检查方式。
