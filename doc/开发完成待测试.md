## 3. 未变更的既有资产

- 数据库：无增量 DDL。`repair_leave_request` 表、索引与实体在 PLAN-9 之前已存在。
- 前端：`WorkerLeaveView`、`AdminLeaveApprovalsView` 占位页面保持原样，不接入新接口。
- 自动派单：复用既有 `RepairDispatchService.dispatch()` 与 `DispatchSourceType.LEAVE_REASSIGN`（来源码 4），派单候选 SQL 已内置请假人员过滤；审查阶段为其增加 `LEAVE_REASSIGN` 专属防线（派单前校验工单仍属于请假人员，CAS 未命中时重查，已不属于请假人员的工单视为已处理成功，不影响其他派单来源）。
