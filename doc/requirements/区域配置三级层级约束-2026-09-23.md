# 区域配置四级层级约束

## 变更范围

管理员端的区域配置必须严格采用以下四级关系：

1. 学校/单位。
2. 区域。
3. 楼栋。
4. 房间。

## 交互规则

- 区域树默认折叠，只展示学校/单位根节点；点击节点行展开或收起下级节点。
- 页面右上方提供“编辑”按钮，默认浏览状态不显示增删入口。
- 进入编辑状态后，学校/单位节点右侧显示 `+` 和 `-`，其中 `+` 只能添加区域。
- 进入编辑状态后，区域节点右侧显示 `+` 和 `-`，其中 `+` 只能添加楼栋。
- 进入编辑状态后，楼栋节点右侧显示 `+` 和 `-`，其中 `+` 只能添加房间。
- 进入编辑状态后，房间节点只显示 `-`，不能添加子节点。
- 进入编辑状态后，列表最下方显示“新增学校/单位”入口。
- 新增弹窗不提供节点类型选择，节点类型根据父节点自动确定。
- 页面不显示固定层级关系提示框。
- 学生提交报修时，房间使用下拉框，并根据所选楼栋加载房间列表。
- 校区、区域或楼栋变化后，必须清空并重置全部后续下拉框。

## 数据约束

- 无父节点时只能创建学校/单位类型。
- 学校/单位的子节点只能是区域。
- 区域的子节点只能是楼栋。
- 楼栋的子节点只能是房间。
- 房间下新增节点的请求必须被拒绝。
- 同一父节点下不允许出现同名节点。
- 存在下级节点的学校/单位、区域或楼栋不得删除，并提示“请先删除下级节点”。
- 房间以及没有下级节点的楼栋、区域、学校/单位可以在确认后删除。

## 删除能力的实现口径（2026-09-24 确认）

后端暂无区域删除接口，前端按以下口径实现，待后端补充删除接口后开放：

- 有下级节点的节点：删除按钮可点击，点击提示“请先删除下级节点”（F4-01 要求）。
- 无下级节点的节点（含房间）：删除按钮禁用，title 提示“后端暂无删除接口，暂不支持删除节点”。
- 故障类型管理页同理：删除按钮禁用并提示。
