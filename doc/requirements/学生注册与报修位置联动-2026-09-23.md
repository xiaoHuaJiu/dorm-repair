# 学生注册与报修位置联动

## 学生注册

- 登录页提供“登录 / 学生注册”切换。
- 注册字段包括 `username`、`password`、`confirmPassword`、`realName`、`phone`。
- 仅允许注册学生账号，服务端固定写入 `role_type = STUDENT`，客户端不得选择角色。
- 校验必填项、用户名唯一、两次密码一致和手机号格式。
- 注册成功后返回登录表单，不自动建立登录会话。

## 报修位置

- 校区、区域、楼栋均使用下拉框，初始值为空。
- 打开报修弹窗时读取后端返回的区域架构树。
- 选择校区后生成该校区下的区域选项，并清空楼栋。
- 选择区域后生成该区域下的楼栋选项。
- 未选择上级节点时，下级下拉框禁用。
- 房间继续使用文本输入框。
