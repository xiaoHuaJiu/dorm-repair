# 维修工作台全部工单与全生命周期轨迹

## 维修人员工作台

- “我负责的维修工单”只展示当前登录维修人员负责且处于维修中的工单。
- 在该卡片下方增加“全部工单”，展示当前学校的全部工单。
- 全部工单条目展示工单号、故障标题、位置、故障类型、负责人、期限、当前状态和异常标记。
- 维修人员可以进入任意工单详情；非本人负责的工单详情为只读，不提供维修操作。

## 工单生命周期轨迹

- 学生端、维修人员端和管理员端的工单详情使用同一份生命周期轨迹数据。
- 轨迹至少记录学生提交、系统派单、维修人员接单、开始维修、处理记录、材料登记、提交维修完成、学生确认完成等节点。
- 自动派单失败、人工派单、接单超时、转派申请与审批、转派失败、维修中断与恢复、返工、二次返工、学生取消、请假转派及管理员待办等异常节点必须保留。
- 每个节点展示时间、操作主体、动作、状态变化、说明及负责人变化。
- 轨迹按时间保存，页面按最新节点在上方展示；历史节点不得被后续状态覆盖。
