# 需求文档

本目录用于保存宿舍报修系统的用户原始需求、需求澄清、范围变更和验收标准。

## 建议内容

每项需求至少应说明：

- 背景与目标。
- 使用者及适用场景。
- 功能范围与不包含的范围。
- 主要业务流程和异常流程。
- 业务规则、状态变化及时限要求。
- 权限与数据可见范围。
- 可验证的验收标准。
- 已确认的变更记录。

## 编写约束

- 保留用户原始表述，并将分析结论与原始需求分开记录。
- 不明确的内容标记为“待确认”，不得作为既定规则直接实现。
- 范围或验收标准变化时，应记录变化原因、确认结果和影响范围。
- 与架构、接口、数据库或安全设计有关的结论，应同步更新对应目录中的文档。
