# 架构文档

本目录用于描述系统边界、模块职责、模块关系、数据流和关键技术决策。

## 当前架构基线

项目采用前后端分离的单体架构：

- 前端基于 Vue 3 和 Vite，学生端、维修人员端使用 Vant，管理端使用 Element Plus。
- 后端基于 Java 17+ 和 Spring Boot 3，通过 Spring MVC 提供接口。
- Spring Security 与 JWT 负责身份认证和权限控制。
- MyBatis 访问 MySQL 8，Redis 提供缓存、并发控制和提醒去重能力。
- MinIO 存储业务图片，Spring Scheduling 执行已确认的定时任务。
- Nginx 与 Docker Compose 用于部署；实时通知可在后续需求明确后扩展 SSE。

## 建议内容

- 系统上下文与边界。
- 前端应用、后端模块及基础设施之间的关系。
- 核心业务流程和数据流。
- 模块职责、依赖方向和接口边界。
- 缓存、并发控制、文件存储和定时任务设计。
- 部署拓扑及环境差异。
- 关键技术决策、备选方案和取舍依据。
- 性能、可用性、可维护性和扩展性约束。

架构文档应描述已确认的设计，不得用未经确认的假设替代业务需求。
