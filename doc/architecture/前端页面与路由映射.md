# 前端页面与路由映射

本文对应 `FRONTEND-PLAN.md` 的 F0-01，作为 HTML 原型还原到 Vue 前端工程的页面基线。原型只用于确认视觉、布局与交互，不作为运行时数据源；正式页面不得读取 `prototype/assets/data.js` 或浏览器本地演示状态。

## 1. 路由原则

- 登录与注册使用公共布局；注册是登录页内的表单切换，不单独建立业务入口。
- 学生端和维修人员端使用移动端布局，管理员端使用桌面侧边栏布局。
- 工单详情统一使用后端工单主键 `:id`，页面展示的工单编号不是路由主键。
- `student-repair-create.html` 仅保留为原型兼容入口；正式功能是学生首页内的提交报修弹窗。
- `admin-settings.html` 不在已确认导航中，不纳入首期 Vue 路由。

## 2. 公共页面

| HTML 原型 | Vue 路由 | 页面组件 | 入口与跳转 | 公共能力 |
|---|---|---|---|---|
| `login.html` | `/login` | `views/auth/LoginView.vue` | 匿名入口；登录后按角色进入各端首页；注册成功返回登录表单 | 公共表单、密码输入、错误提示 |
| 无独立原型 | `/403` | `views/system/ForbiddenView.vue` | 路由守卫或接口 403 | 结果页 |
| 无独立原型 | `/:pathMatch(.*)*` | `views/system/NotFoundView.vue` | 未匹配地址 | 结果页 |

## 3. 学生端

| HTML 原型 | Vue 路由 | 页面组件 | 入口与跨页跳转 | 端内差异 |
|---|---|---|---|---|
| `student-home.html` | `/student/home` | `views/student/StudentHomeView.vue` | 登录落点；进入工单详情；打开报修弹窗 | 展示本人进行中工单和全校工单 |
| `student-repair-create.html` | 无独立路由 | `components/student/RepairCreateDialog.vue` | 由首页右上角“我要报修”打开 | 四级位置级联、重复报修确认 |
| `student-orders.html` | `/student/orders` | `views/student/StudentOrdersView.vue` | 底部“我的工单”；进入详情；可取消工单 | 只查询本人发起工单 |
| `student-order-detail.html` | `/student/orders/:id` | `views/student/StudentOrderDetailView.vue` | 从首页或我的工单进入；进入确认评价 | 显示取消、确认或返工入口 |
| `student-order-review.html` | `/student/orders/:id/review` | `views/student/StudentOrderReviewView.vue` | 从待确认工单详情进入；完成后返回详情 | 确认、评分、评价、返工 |

学生端底部导航固定为“首页、我的工单”。

| 组件 | 使用页面 |

| `ConfirmDialog` | 取消、删除、启停、审批、派单等操作 |
| `ImageUploader` | 学生报修、维修记录、完成维修 |
| `MobileAppShell` | 学生端、维修人员端 |
| `AdminAppShell` | 管理员端 |

## 7. 验收口径

- 表中每个纳入范围的 HTML 原型都有且只有一个明确的 Vue 承载页面或弹窗。
- 列表到详情均通过整卡片或整行点击进入，内部操作按钮必须阻止冒泡。
- 三端详情复用同一生命周期展示语义，但按角色使用独立接口和操作权限。
- 所有业务数据来自 API；加载失败或无数据时使用状态组件，不回退到演示数据。
