# 前端视觉基础规范

本文对应 `FRONTEND-PLAN.md` 的 F1-03。后续页面以现有 HTML 原型为视觉验收依据，本规范只统一跨页面令牌，不替代逐页对照。

## 设计方向

- **识别元素**：使用高辨识度的报修红作为主要操作和当前状态提示，延续原型中“宿修通”的红色主题。
- **信息承载**：背景使用冷灰白，业务卡片保持白色；用边框和间距区分信息层级，避免所有区域都使用重阴影。
- **三端差异**：学生端和维修人员端保持较宽的移动工作台体验；管理员端使用固定侧栏和高密度表格内容区。
- **文字**：使用适合中文界面的系统无衬线字体，标题粗而紧凑，正文保持清晰行高，不引入网络字体依赖。

## 核心色板

| 名称 | 色值 | 用途 |
|---|---|---|
| 报修红 | `#EC383E` | 主按钮、当前导航、关键状态 |
| 深报修红 | `#BD2027` | 按下状态、强调文字 |
| 浅报修红 | `#FFF0F1` | 选中背景、轻量提示 |
| 页面灰 | `#F5F6F8` | 页面背景 |
| 墨黑 | `#15171A` | 标题和主要正文 |
| 边框灰 | `#E1E4E8` | 卡片、表格和表单边界 |

完整令牌位于 `frontend/src/styles/tokens.css`。Element Plus 和 Vant 的主题变量均从同一组令牌映射，后续页面不得各自定义不同的主色。

## 布局基线

- 顶栏基准高度：`72px`。
- 移动业务内容最大宽度：`960px`。
- 管理端侧栏宽度：`240px`，内容最大宽度：`1440px`。
- 底部导航基准高度：`64px`。
- 常用圆角分为 `8px`、`12px`、`18px` 三档，按控件、卡片、重点容器使用。

## 可访问性

- 所有键盘交互元素必须具有可见焦点。
- 颜色不能作为状态的唯一表达，状态标签必须同时显示文字。
- 尊重 `prefers-reduced-motion`，非必要动画在减少动态模式下关闭。
- 空状态和错误状态提供明确说明及可执行的下一步，不用演示数据填充页面。
